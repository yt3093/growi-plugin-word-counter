# growi-plugin-word-counter

GROWI ページ本文（閲覧モード）の先頭に、文字数・単語数・読了時間の目安を表示する GROWI Script プラグインです。

## 特徴

- 文字数（空白含む / 空白除く）・単語数・読了時間をアイコン付きで表示
- 日本語の単語分割に対応（`Intl.Segmenter` を使用。スペース区切りが無い日本語文でも意味のある単語単位でカウント。未対応の古いブラウザではスペース区切りにフォールバック）
- コードブロック・drawio 図・mermaid 図・PlantUML 図・KaTeX 数式・脚注の参照マーカー・添付ファイルのプレビュー・GROWI の見出し/表の編集ボタンなど、実際に「読む文章」ではない部分は自動でカウントから除外（実機の GROWI DOM で検証済み）
- コメントが付いているページでも、本文とコメントを正しく区別してカウント
- 閲覧モードのみで動作（編集画面・管理画面・印刷時は非表示）
- ページ遷移（SPA 遷移・本文の動的な変化）にも自動追従して再計算
- ダークモード対応（OS 設定・GROWI UI トグルの両方）
- 絵文字・外部アイコンフォントを使わず、自己完結の SVG アイコンのみで構成
- 外部ライブラリ・外部通信なしの自己完結プラグイン（`innerHTML` 不使用、XSS リスクなし）
- 想定外の DOM 構造に遭遇してもエラーを握りつぶさずログに残しつつ処理を継続（1ページの失敗でプラグイン全体が止まらない）
- Vitest による自動テストで主要ロジックを継続的に検証

## 表示イメージ

ページ本文の先頭に、以下のような統計がアイコン付きで並びます（背景・枠線のないミニマルな見た目で、下端の薄い罫線のみで本文と区切られます）。

```
Ⓐ 1,234 chars   ⇄ 987 chars (no spaces)   💬 240 words   🕐 ~2 min read
─────────────────────────────────────────────────────────
（本文がここに続く）
```

## インストール

1. GROWI 管理画面の `/admin/plugins` を開く
2. このリポジトリを指定してプラグインを追加する
3. 有効化する

コードを更新した場合、管理画面の「有効/無効」トグルだけでは反映されません。確実に反映するには `/admin/plugins` で一度**削除してから再インストール**してください。

## 使い方

ページを閲覧すると、本文の先頭に文字数などの統計が自動で表示されます。特別な設定は不要です。

### 特定ページで非表示にする

ページ本文（`.wiki` 要素）に `data-no-wordcount` 属性が付与されている場合、そのページではウィジェットが表示されません。

## 開発

```bash
pnpm install
pnpm dev         # 開発サーバー
pnpm test        # Vitest でテストを実行
pnpm test:watch  # テストをウォッチモードで実行
pnpm build       # dist/ に本番ビルドを出力
```

ビルド成果物（`dist/`）は GROWI が静的配信するファイルなので、**必ず git にコミット**してください（`pnpm install` / `pnpm build` は GROWI 側では実行されません）。

実装方針・アーキテクチャ・ハマりどころなど詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## 動作要件

- モダンブラウザ（`Intl.Segmenter` 対応環境を推奨。未対応環境では単語数がスペース区切りでのカウントにフォールバックします）
- Script プラグインに対応した GROWI
